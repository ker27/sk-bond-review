工作流五步

1
清点源文件

先 ls 源文件目录，弄清每份文件是什么：说明书本体（.docx，复核对象）、基础资产方财报（Excel）、增信/担保方财报（Excel 或审计报告 PDF + 半年报 Excel）、审计报告（.pdf，附注是金矿）、资料补充清单、现金流预测模型。

2
抽取全部文档

用 scripts/ 下的脚本把每个文件转成可检索文本：说明书按段落 [P#]+表格 ===TABLE#N===，Excel 输出 坐标=值，PDF 用 pdfplumber。抽取后先通读目录，建立「第X章/X.X节 → 段落区间」定位表。说明书文本可直接粘贴到上方工作台跑机械扫描。

3
逐块核对

按「核对清单」A–E 五类逐项检查：表内勾稽每张表重算、跨章节一致性、指标公式复核、占位符扫描、文字质量。大文件按 ~500 行分块核对。

4
源文件自身问题单独报告

说明书与源文件不一致时先判断谁对（用勾稽关系）。源文件自身矛盾（报表符号异常、补充清单不自洽、审计重述信号）也要报。

5
输出报告（按章节定位）

定位用「第几章第几节」，不要用表号。每条写清：位置（原文短语可 Ctrl+F）+ 问题 + 应为值 + 证据（源文件名），标【高】【中】【低】。核对无误的章节明确写"未发现错误"。

关键坑（实测踩过）

数据抽取类
  • Excel 列映射先侦察再取值：利润表"本年累计"可能在 D 列（E 列读到 0）；资产负债表资产在 C/D 列、负债权益在 G/H 列；审计版 Excel 有"合并调整"列和多家子公司列，发债口径可能在 J/T 列——maxcols 给足 21，先把「坐标=值」全部 dump 出来看结构。
  • openpyxl 必须 data_only=True；取到 None 说明公式无缓存值，用 Excel 打开另存一次。
  • PDF 扫描件无文本层：审计报告正表页常是扫描图。对策：找同名数字版 Excel（"XX版本半年报202606.xlsx"），审计 PDF 只看附注页（有文本）。
  • docx 合并单元格：row.cells 会重复同一格，用 row._tr.findall(qn('w:tc')) 遍历。
  • 大文件分块主循环自己核，不要依赖并行 agent（实测 4/6 因账户 402 失败）。
判定类
  • 审计报告"上年数"已重述：典型错误是说明书 2024 净利润写 894.25 万，审计上年数是 1,634.19 万（所得税从 441.53 万调成 −298.40 万）——说明书没跟着重述。
  • 区分容差和真错：0.01/0.84 万是四舍五入容差；差 2,266,472 元（剩余账期两行合计≠总计）是真错。
  • 单位混用：元/万元/亿元混排，汇总前统一；"17,40"这类缺位（应为 1,740.00）只在重算合计时才能发现。
  • 担保公司特有科目：担保赔偿准备金/未到期责任准备在销售费用与预计负债；应收代偿款账面余额−减值=账面价值；信用减值损失正负号要与营业利润公式对一遍。
  • 现金流预测表"表内数值无法复算"（覆盖倍数 1.04375 用表内数算不出来）是典型模型错误，必须逐列重算，不能只看合计。

输出报告格式模板

定位用"第几章第几节"，不要用表号。每条写清"说明书写的是什么 / 源文件是什么 / 哪个对、应改为多少"。核对无误的章节也明确说"未发现错误"。

# 全文问题清单（按章节定位） ## 第X章 标题 ### X.X 节名 - 位置描述（引用原文短语，便于 Word 里 Ctrl+F）+ 问题 + 应为值 + 证据（源文件名） 【高】勾稽不平 / 数据矛盾 / 重述未更新 / 被引用的空表 【中】占位符、文字错误、术语/口径不一致 【低】标点、格式 ## 附：源文件自身的问题
示例写法：高5.1.2「截至2026年6月30日…实收资本为人民币20,077.32万元」与同章财务报表表（2026年6月末列 21,185.32 万元）矛盾 → 应改为 21,185.32 万元（证据：说明书 5.1 资产负债表 T#16 实收资本行）

级别位置/主题发现

中5.1.2 担保责任余额"占净资产 3.12%" 应为 "3.12 倍"；"委托贷款减值 0 亿" 应为 "0.42 亿"（审计报告计提委贷减值 4,200 万）
中5.1.8 前五名欠款方名称多"管理"二字；占比"97%以上"应为 96.32%；增长率 159.34% 应为 259.34%
中占位符批量「截至，」「截至202年末」「【2026】年【4】月【14】日」、授信 100 行空表、净利润率整行空白
